# THE YOUTH LABEL

> *For the Youth That Leads.*

A premium, modern boyswear e-commerce website for boys aged 3–14 years, built with HTML5, CSS3, and Vanilla JavaScript.

## Highlights & Features
- **Modern Responsive Design**: Fully responsive across mobile, tablet, laptop, and desktop displays.
- **Brand Identity**: Signature smoke grey, black, and white design language with custom brand logo and banners.
- **Shop & Dynamic Filters**: Shop All catalog with category navigation (T-Shirts, Shirts, Trousers & Joggers, Co-ord Sets, New Arrivals), live search, and sorting.
- **Product Details & Gallery**: Multi-angle image views, age-based size selection (3–14 Years), quantity adjustments, and accordion details.
- **Cart & Wishlist**: Complete browser `localStorage` persistence, dynamic count badges, real-time total calculations, and item migration between wishlist and cart.
- **Checkout & Order Flow**: Multi-step checkout with customer info, address validation, payment selector, and unique order reference generation.
- **User Authentication & Accounts**: Frontend customer registration, login state persistence, profile editing, and order history tracking.

## Technology Stack
- **HTML5**: Semantic structure and accessible markup
- **CSS3**: Custom variables, Flexbox, Grid, fluid typography, and responsive media queries
- **Vanilla JavaScript**: Zero external dependencies or frameworks
